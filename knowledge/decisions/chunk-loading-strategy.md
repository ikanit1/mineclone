# ADR: Стратегия загрузки чанков

## Решение

`ChunkLoader` генерирует чанки в фоновом пуле потоков. Результаты — `Ready`-записи, которые `Game` загружает на GPU в главном потоке.

## Почему

- Генерация — CPU-тяжёлая операция, нельзя блокировать игровой цикл
- Загрузка на GPU требует main thread (OpenGL не потокобезопасен)

## Параметры

- `RENDER_RADIUS = 6` в `Game` — радиус отрисовки чанков
