## Аудит остальных текстур

Просмотрен контактный лист всех PNG папки `assets/textures/blocks` (после правок
141 файл). Разный размер исходного PNG сам по себе не означает ошибку: интерфейс
и частицы могут иметь другую плотность пикселей. Для остального мира отмечены
следующие отдельные художественные задачи; эти ассеты в этом наборе не заменены:

1. **Приготовленная еда:** `cooked_beef`, `cooked_pork`, `cooked_chicken`,
   `cooked_mutton` имеют один и тот же силуэт (108 непрозрачных пикселей в 16×16).
   Цвета немного различаются, но виды мяса плохо различимы. Нужны четыре формы.
2. **Сундук и дверь:** простые полосы/рамки и 5–8 цветов в 16×16 заметно проще
   фактурных досок 32×32. Это наиболее заметная оставшаяся группа для перерисовки;
   стороны и верх следует делать одним набором, учитывая ориентацию в мешере.
3. **Верстак и печь:** исходники 16×16 и другой масштаб деталей рядом с новыми
   каменными поверхностями. Нужна совместная проверка рабочего фронта, боков и верха.
4. **Листва/трава/кактус:** более яркая зелёная палитра, чем у остальных природных
   материалов. Это стилевое отличие, а не доказанная ошибка назначения текстуры;
   насыщенность надо оценивать на биомах с игровым освещением.
5. **Вода:** `water.png` 32×32 и `water_flow_00..15` 16×16 выглядят по-разному
   на диске. В мире шейдер уже переводит и стоячую, и текущую воду на анимационный
   ряд (4 и 6 кадров/с), поэтому одного контактного листа недостаточно для вывода
   о шве в мире. Статическая иконка использует исходный тайл и отличается от воды.
6. **Лук/стрела:** остаются прежними 16×16. Этапы натяжения проверены существующим
   предпросмотром; при будущей перерисовке нужен согласованный набор всех стадий.

Снимки уже существовавших изменений персонажа использованы для проверки
совместимости. Посторонние незакоммиченные правки не откатывались.

## Воспроизведение

```powershell
python tools/import_equipment_pack.py
.\run-tests.ps1
javac -encoding UTF-8 -cp 'out-test;libs/*' -d out-test tools/RenderEquipmentReview.java tools/RenderHeldPlayerPreview.java
java -cp 'out-test;libs/*' RenderEquipmentReview
java -cp 'out-test;libs/*' RenderHeldPlayerPreview
```

Импорт не обращается к сервису и не тратит генерации повторно. Исторический
`ImportToolTextures.java` относится к набору от 20 сентября и перезаписывает
часть этих файлов — его не следует запускать для нового набора.
