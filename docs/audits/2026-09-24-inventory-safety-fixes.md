Исправлены пять воспроизводимых ошибок из [первоначального аудита](2026-09-24-current-state.md).
Работа выполнена поверх существующих незакоммиченных изменений; пользовательские миры не использовались.

## Поведение после исправлений

| Сценарий | Результат |
| --- | --- |
| Выход с ингредиентами в сетке крафта | Ингредиенты, курсор и ожидающий выброс входят в сохранение. При штатном выходе окно также возвращает временные предметы перед записью мира. |
| Переподключение гостя | Хозяин восстанавливает инвентарь по постоянному UUID, независимо от имени игрока. Состояние сохраняется и между перезапусками процессов. |
| Выброс предмета гостем | Хозяин создаёт предмет и записывает состояние инвентаря после списания. Следующий снимок мира содержит настоящий выброс. |
| Одновременное взятие из сундука | Каждый перенос выполняется на хозяине. Клик по устаревшему содержимому отклоняется, окно получает актуальные слоты. |
| Закрытие работающей печи | Гость не отправляет итоговое содержимое и таймеры. Переплавка принадлежит хозяину и продолжает отображаться в открытом окне. |

Дополнительно подбор предметов согласован с сохранением инвентаря: следующий подбор, выброс и перенос ждут ответа хозяина. Открытие сундука не может затереть только что подобранную стопку. Частичный подбор оставляет остаток на земле. При отключении до получения ответа используется уже принятое хозяином состояние.

Операции контейнеров используют общие правила `ContainerMenu`: разделение стопки, Shift, цифровые клавиши, двойной клик, распределение мышью и выброс. Закрытие или отключение возвращает курсор один раз; переполнение создаёт предмет на хозяине. Старые пакеты полной замены сундука/печи больше не применяются.

## Сохранения и совместимость

- Форматы существующих `level.dat`, чанков и настроек не менялись. Для временных вещей используется существующее поле `pending`.
- UUID установки хранится в `player-id.txt` рядом с `options.dat`. При переносе установки этот файл нужен для восстановления прежнего сетевого персонажа.
- Хозяин хранит гостей в `saves/<world>/players/<uuid>.dat`. Записи выполняет существующий фоновый поток с атомарной заменой каждого файла. Повреждённое сохранение не заменяется молча пустым инвентарём: вход отклоняется.
- **Сетевой протокол — версия 7.** Хозяин, выделенный сервер и клиенты должны использовать новую совместимую сборку.
- Это защита от проверенных ошибок обычной игры и переподключения. Записи мира и игрока не образуют единую транзакцию на случай аварии процесса или отключения питания; защита от намеренно модифицированного клиента не добавлялась.
