# Требования LW-08

1. Шрам регистрируется только после настоящего потребления топлива огнём,
   над поддерживаемой почвой, в загруженном доступном для записи чанке.
   При выключенном Living World прежний путь огня и симуляции сохраняется.
2. Учёт ограничен 16 записями на регион, 64 точными клетками земли на запись
   и 1024 байтами записи, включая непрозрачный хвост. Повторный пожар обновляет
   клетку, не создавая дубликат.
3. Выгоревшая земля постепенно получает траву и природные саженцы только
   внутри зарегистрированного шрама. Зарастание не заменяет блоки построек,
   чужие растения, уцелевшие деревья или защищённые данные.
4. Природный саженец использует обычный рост FARM-03, проверяет всю крону до
   записи и получает первый тик относительно настоящего логического дня посадки.
5. Обычные сутки, `/ecology advance` и возвращение загруженного участка
   применяют одну ограниченную детерминированную последовательность.
6. Зелень и ёмкость учитывают повреждение и восстановление. Живые животные
   покидают повреждённое место через обычное движение; материализация новых
   конечных тел избегает его до восстановления и сохраняет прежние капы и ID.
7. Сохранение/открытие удерживает даты, посадку один раз, неизвестные записи
   и хвосты. Будущая известная версия защищает исходные данные; повреждённая
   запись пересоздаётся только после сохранения доказательств.
8. Гость получает обычные блоки/метаданные/снимки, не управляет экологией и не
   симулирует восстановление. Игра и dedicated server используют один host путь.
