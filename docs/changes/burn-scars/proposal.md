# Пожарища и восстановление леса: LW-08

Настоящий пожар при включённом Living World оставляет сохраняемые участки
выгоревшей земли. Повреждённое место временно теряет зелень и привлекательность
для животных; затем трава и новые деревья восстанавливают лес.

Работа продолжает `323796a` (LW-04/LW-05), включая предыдущую серию с GitHub.
Добавляются ограниченные BURN-записи внутри существующих слотов `ecology`,
суточная последовательность восстановления и связь с обычными саженцами FARM-03.
Новые блоки, пакеты и форматы заголовков не требуются.

Реальная приёмка должна включать поджог через Game, выгоревшую рощу и молодых
деревьев через семь суток, движение/возвращение конечных животных, сохранение,
LAN и NORMAL сервер с двумя клиентами. Полные истории LW-11 и аппаратный бюджет
LW-12 остаются отдельными задачами.
