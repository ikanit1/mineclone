# Требования LW-04 / LW-05

1. `livingWorld=off` сохраняет прежний спавн. При включённом правиле новые
   пауки происходят из живого сердца и учитываются в ограничении враждебных
   тел участников; выпуск не прибавляет второй раз региональную численность.
2. Логово ограничивает численность, выпуск и территорию. Смерть расходует
   конкретный выпущенный ID один раз; рассвет возвращает представление без
   потери популяции. Уничтоженное сердце больше не выпускает и не растёт;
   бродящие тела сохраняют свою личность до смерти или обработки host.
3. Сердце — добавленный в конец ID `SPIDER_NEST`; нормальное ломание даёт
   предусмотренную добычу нити и уничтожает связанное логово. Паутина растёт
   запланированными тиками только в подходящих полостях его территории.
4. Чанк хранит до 16 кандидатов `lair_spots`. Место имеет полную опору 2×2,
   свободное тело паука, сырую небесную и блочную освещённость 0 и настоящую
   непрозрачную крышу. Обнаружение и выбор не генерируют соседние чанки.
5. Раз в сутки регион без живого логова получает детерминированную возможность
   заселения. Для единственного уничтоженного логова другое подходящее
   загруженное место находится через 3–10 суток, без возврата в старый радиус.
6. Выбор отвергает текущий свет, закрытую полость, read-only чанк, близость
   участника или существующей загруженной базы менее 32 блоков, живого логова
   ближе `max(64,2×radius)`, старой территории ближе `max(48,2×radius)` и
   видимость с пути последних трёх дней в пределах 96 блоков. Отсутствие
   участника не снимает защиту CHEST/FURNACE/BEDROLL.
7. Lair записи не превышают 1024 байт; LSPT v1 не превышает 1062 байт.
   Неизвестные хвосты проходят round-trip. Будущая известная версия защищает
   исходные байты; повреждение обрабатывается существующей политикой saves.
8. Восстановление предшествует публикации и выпуску. Повторное открытие
   сохраняет сердце, разрушение, выпущенные ID, численность и кандидаты.
   Host управляет ломанием, выпуском, возвращением и блоками для обоих гостей.

Приёмка выполнена: настоящая игра, три ночи после зачистки, новое сердце на
восьмые сутки, сохранение/открытие, LAN и NORMAL сервер с двумя гостями.
