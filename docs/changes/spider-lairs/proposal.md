# Паучьи гнёзда и заселение: LW-04 / LW-05

При включённом `livingWorld` пауки должны происходить из конечного гнезда,
которое игрок может найти по паутине и уничтожить. Зачистка убирает источник
пауков в этой территории; позже мир может заселить другую тёмную пещеру.
Обычный режим с выключенным правилом сохраняет прежний спавн.

В эту поставку входят сердце `SPIDER_NEST`, региональный `Lair`, таблица
`ecology/lairs/spider_nest.json`, ночной выпуск и рассветное возвращение тел,
убыль от смерти, рост паутины, сохранённые кандидаты пещер и дневной
`Colonizer`. Новые блоковые ID добавляются только в конец перечисления.

Заселение работает только в загруженной доступной для записи местности.
Свет, недостаточная полость, близкая база, живое логово, старая территория
и видимость с недавнего пути участника исключают место. Для единственного
разрушенного логова задержка по сиду составляет 3–10 суток; заселение в этот
срок требует другой подходящей загруженной пещеры региона.

Данные дополняют существующие необязательные секции сохранения. Неизвестные
хвосты сохраняются, известные будущие версии защищаются от перезаписи.
Уровень остаётся в формате 11. Новый ID блока требует формат чанка 9 с
минимальным читателем 9: прежняя сборка отказывается от записи такого чанка,
сохраняя исходные байты. Совпадающие сетевые сборки используют протокол 13.

Приёмка LW-04/LW-05 выполнена: полный runner, настоящий ночной цикл, три ночи
после зачистки, новое сердце на восьмые сутки, повторное открытие сохранения,
LAN и NORMAL dedicated server с двумя гостями. [Доказательства](validation.md).
