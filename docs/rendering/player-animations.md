# Анимации игроков

Обновлено 2026-09-23. `PlayerAnimation` хранит отдельное состояние каждого игрока и обновляется один раз за кадр после движения. Локальная модель в третьем лице и сетевые игроки используют одинаковые переходы и позы.

| Состояние | Движение |
| --- | --- |
| Покой | Дыхание, небольшое движение плеч и рук; ноги остаются на земле |
| Ходьба | Фаза от реального пути, плавный разгон и остановка, противофаза рук и ног, перенос веса |
| Бег | Больший размах, наклон корпуса вперёд, движение плеч |
| Назад и вбок | Направление шага учитывается относительно корпуса |
| Прыжок и падение | Ноги и руки переходят в воздушную позу с учётом вертикальной скорости |
| Приземление | Короткое сжатие ног и наклон корпуса с плавным восстановлением |
| Вода | Чередующиеся гребки и движение ног от времени, в том числе без горизонтального перемещения |
| Творческий полёт | Расслабленные ноги, разведённые руки, наклон по скорости |
| Удар и добыча | Подготовка, вынос руки с поворотом корпуса, возврат; повторные удары завершают текущую дугу |

Сглаживание экспоненциальное, пружина приземления рассчитывается аналитически. Темп шага — `STRIDE_RADIANS = 2.6` радиана на блок. При телепорте и возрождении предыдущая поза сбрасывается. Пауза и фоторежим не продвигают локальную анимацию.

Верх тела поворачивается от бёдер: плечи, шея и предмет следуют за корпусом. Голова компенсирует наклон корпуса и сохраняет направление взгляда. Коррекция высоты по нижним углам стоп удерживает опорную ногу на плоскости земли. Риг остаётся блочным, без новых коленных и локтевых суставов.

`PlayerRenderer` использует одну позу и общий расчёт матриц для цвета, тени и ладони. Старые перегрузки с числовой фазой сохранены для прежних инструментов предпросмотра; живые игроки используют `PlayerAnimation.Pose`. Анимация первого лица сохраняет собственный счётчик пути.

В сети новые поля пакета не нужны: используются существующие флаги земли, воды, полёта, бега и событие удара. Позиция линейно интерполируется за сетевой интервал, чтобы не тормозить модель заново при каждом пакете; параметры позы дополнительно сглаживаются.

## Проверки

- `run-tests.ps1`: 422 проверки, 0 ошибок на момент изменения. `PlayerMotionTests` проверяет 30/60/144/240 FPS, остановку, переходы, приземление, телепорт, крепления, контакт стоп и движение при 12 Гц сетевых снимков.
- `RenderPlayerMotion`: 800 проходов цвета и глубины, восемь состояний, 100 кадров анимации. Каждый проход тени проверяется на непустую глубину и ошибки OpenGL. Листы поз просмотрены.
- Этот прогон использует настоящий OpenGL и синтетические движения. Ручная игра и отдельный живой сеанс LAN/Photon в этой задаче не проводились.

```powershell
.\run-tests.ps1
javac -encoding UTF-8 -d out-test -cp 'out-test;libs/*' tools/RenderPlayerMotion.java
java -cp 'out-test;libs/*' RenderPlayerMotion
```
