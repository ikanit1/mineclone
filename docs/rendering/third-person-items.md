# Предметы в руках от третьего лица

Обновлено 2026-09-22.

`PlayerRenderer` теперь рисует выбранный предмет у собственного персонажа в третьем лице и у удалённых игроков. Точка хвата получается из матрицы активной руки: предмет повторяет ходьбу, поворот корпуса и замах, без отдельной приблизительной анимации. Неравномерный масштаб руки убирается из матрицы хвата, поэтому инструмент не растягивается.

`ThirdPersonItemRenderer` использует общий `HeldToolTemplate` для всех 18 инструментов. Блоки используют существующие меши предметов первого лица, а обычные предметы — объёмный силуэт собственной иконки. Факел имеет отдельный масштаб. Цветовой проход сохраняет глубину мира и получает мировое освещение; предмет не просвечивает сквозь персонажа или стены. Та же поза рисуется в карту теней. Удалённые игроки вместе с предметами также включены в проход теней.

Протокол **v5** добавляет `X_PLAYER_EQUIPMENT`: идентификатор предмета и номер обновления. Изменения надёжно отправляются при смене предмета, при выдаче сведений новому участнику и периодически. Пустая строка освобождает руку; неизвестный идентификатор, устаревший номер или оборванный пакет сохраняют последнюю корректную вещь. Передаётся только внешний вид выбранного предмета, не содержимое инвентаря и не право выдавать вещи. До проверки версии хозяин отправляет только совместимые сведения, чтобы старая сборка могла прочесть отказ.

Проверки:

- 373 теста: все варианты инструментов, передача в обе стороны, смена на блок и пустую руку, ошибочные пакеты, привязка хвата к фактической матрице руки.
- `RenderHeldPlayerPreview`: 21 предмет, 42 сравнения с пустой рукой с двух ракурсов, для каждого предмета подтверждено изменение карты глубины тени; ошибок OpenGL нет.
- LAN и Photon Cloud: два настоящих игровых клиента подтвердили железную кирку хозяина и алмазный топор гостя; игровой снимок LAN просмотрен.
- Выделенный сервер: оба клиента подтвердили передачу выбранного предмета другого игрока через сервер, завершились успешно; сервер сохранил мир и штатно остановился.

Повторить превью после компиляции игры:

```powershell
javac -encoding UTF-8 -cp 'out;libs/*' -d out-test tools/RenderHeldPlayerPreview.java
java -cp 'out;out-test;libs/*' RenderHeldPlayerPreview
```

Локальные артефакты: `out-test/previews/third-person-items/poses.png`, `all-items.png`.
