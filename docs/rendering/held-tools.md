# Шаблоны инструментов в первом лице

`HeldToolTemplate` задаёт общую позу, масштаб и анимацию всех инструментов.
В покое рукоять выходит из нижней правой части экрана, рабочая часть
направлена вверх-вправо; рука для инструментов не рисуется.
Пустая рука и блоки используют прежние отдельные позы.

Для кирки, топора и лопаты используется по одному силуэту — соответствующая
железная иконка из атласа. Материал меняет окраску, не геометрию. Дерево,
камень, железо и алмаз берут пиксели своих согласованных иконок. Золото и
медь используют общую деревянную рукоять и материал рабочей части.
Медная лопата получает силуэт лопаты, даже если её иконка — тайл материала.

`ItemSpriteMesh.buildTool` приводит высоту силуэта к `HeldToolTemplate.HEIGHT`
и совмещает рукоять с `GRIP_X/GRIP_Y`. Изменять положение отдельных материалов
не требуется. Точку на экране, наклон, масштаб, доставание и замах следует
настраивать только в `HeldToolTemplate.pose`.

Проверка всех 18 текущих вариантов после компиляции проекта:

```powershell
javac -encoding UTF-8 -cp 'out;libs/*' -d out-test tools/RenderHandPreview.java
java -cp 'out;out-test;libs/*' RenderHandPreview --all
```

Результат: `out-test/previews/tool-templates.png`. Для одного инструмента,
включая замах, доставание и осмотр, передать префикс снимков и ID предмета:

```powershell
java -cp 'out;out-test;libs/*' RenderHandPreview template iron_pickaxe
```

`PlayerAnimationTests` проверяет одинаковую геометрию материалов одного
класса, непрозрачность всех используемых пикселей, точку вращения осмотра
и опускание инструмента при смене предмета.


Отображение со стороны использует те же шаблоны инструментов и отдельную позу хвата: [предметы в руках от третьего лица](third-person-items.md).
