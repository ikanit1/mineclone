# Мобы E1: первые существа — модели, ИИ, спавн, бой

- **Дата:** 2026-07-13
- **Статус:** одобрен (готов к написанию плана реализации)
- **Sub-project:** E1 из дорожной карты survival (первая часть E «Мобы + бой»)
- **Зависит от:** A (предметы/инвентарь/режимы) — готов

## Цель

Мир пустой — заселить его. Пять мобов: четыре мирных животных днём (корова,
свинья, овца, курица) и зомби ночью с преследованием и melee-уроном. Игрок
может бить мобов рукой. Дроп с мобов НЕ входит (предметов-не-блоков ещё нет —
появятся в подсистеме C).

## Ключевые решения

| Вопрос | Решение |
|---|---|
| Состав | Мирные (корова, свинья, овца, курица) + зомби ночью |
| Архитектура | Лёгкая data-driven система: один класс `Mob`, параметры в enum `MobType` (не ECS, не класс-на-моба) |
| Текстуры | Процедурные пиксельные скины + override из `assets/mobs/<type>.png` |
| Дроп с мобов | Нет (ждёт систему предметов, подсистема C) |
| Персистентность | Мобы НЕ сохраняются в сейв; после перезахода мир заселяется заново |
| Физика игрока | `Player` не трогаем; мобам — отдельный упрощённый `EntityPhysics` |

## Структура файлов

**Новые:**
- `src/main/java/com/mineclone/world/entity/MobType.java` — enum с параметрами
- `src/main/java/com/mineclone/world/entity/Mob.java` — состояние моба + стейт-машина ИИ
- `src/main/java/com/mineclone/world/entity/EntityPhysics.java` — статический AABB-хелпер
- `src/main/java/com/mineclone/world/entity/MobSpawner.java` — спавн/деспавн, капы
- `src/main/java/com/mineclone/render/MobSkins.java` — процедурные скины (BufferedImage, без GL)
- `src/main/java/com/mineclone/render/MobRenderer.java` — коробочные модели, анимация, текстуры

**Правки:**
- `Game.java` — тик мобов + спавнер, вызов рендера, удар ЛКМ по мобам, урон игроку
- `Shaders.java` — новая программа `MOB`
- `Sounds.java` — маппинг MobType → папки `assets/sounds/mob/<name>/`

Пакет `world.entity` не зависит от GL — вся логика юнит-тестируема.

## Данные: MobType

```
enum MobType { COW, PIG, SHEEP, CHICKEN, ZOMBIE }
```

| Поле | COW | PIG | SHEEP | CHICKEN | ZOMBIE |
|---|---|---|---|---|---|
| width (м) | 0.9 | 0.9 | 0.9 | 0.4 | 0.6 |
| height (м) | 1.4 | 0.9 | 1.3 | 0.7 | 1.8 |
| maxHealth | 10 | 10 | 8 | 4 | 20 |
| walkSpeed (м/с) | 0.8 | 0.9 | 0.9 | 0.9 | 0.7 |
| chaseSpeed (м/с) | — | — | — | — | 1.2 |
| hostile | нет | нет | нет | нет | да |
| soundDir | cow | pig | sheep | chicken | zombie |
| особое | — | — | — | медленное падение (терминальная скорость падения ограничена) | горит днём |

Звуки уже лежат в `assets/sounds/mob/<soundDir>/` (idle*.ogg, hurt*.ogg,
death*.ogg) — подключаются через существующий `SoundEngine.playOneOfAt`.

## Физика: EntityPhysics

Статический хелпер, без состояния:

- `step(World, Vector3d pos, Vector3f vel, float width, float height, float dt)` —
  гравитация (как у игрока), осевой AABB-свип по solid-блокам (X→Z→Y),
  возвращает флаги `onGround` и `hitWall` (горизонтальная коллизия).
- В воде — простая плавучесть (мобы всплывают и барахтаются, не тонут насмерть).
- Упрощения относительно Player: без auto-step по лестницам, без MLG-механик,
  без плавания. Упёрся в стену — ИИ решает прыгать.
- Прыжок = вертикальный импульс, тот же порядок величины, что у игрока
  (перепрыгивает 1 блок).

## ИИ: стейт-машина в Mob

Состояния: `IDLE`, `WANDER`, `FLEE`, `CHASE`, `ATTACK`.

**Мирные (COW, PIG, SHEEP, CHICKEN):**
- `IDLE` — стоит, случайный поворот головы; таймер 2–6 с → `WANDER`.
- `WANDER` — случайное направление, идёт 2–5 с → `IDLE`. `hitWall && onGround` → прыжок.
- Удар игрока → `FLEE`: бежит от игрока 5 с на скорости ×1.5 → `IDLE`.
- Idle-звук раз в 5–15 с (случайно), с позиционным аудио.

**Зомби (ZOMBIE):**
- `WANDER`/`IDLE` как у мирных, пока игрок дальше 16 блоков.
- Игрок ближе 16 блоков (без проверки прямой видимости — MVP) → `CHASE`:
  идёт на игрока со скоростью chaseSpeed, `hitWall && onGround` → прыжок.
- Дистанция < 1.5 блока → `ATTACK`: 3 урона игроку (1.5 сердца) +
  горизонтальный knockback игрока, кулдаун 1 с. Дальше 2 блоков → снова `CHASE`.
- Игрок дальше 24 блоков → теряет цель, `WANDER`.
- **Горение днём:** если daylight-фактор > 0.7 (день) и над зомби открытое
  небо (столбец до неба без solid-блоков) — 2 HP/с урона + серые дымовые
  частицы через существующий `ParticleSystem`. Под крышей/в тени не горит.
- **В CREATIVE зомби не агрится и не наносит урон** (остаётся WANDER).

Все переходы детерминированы при подсунутом `Random` — юнит-тестируемо.

## Спавн: MobSpawner

- Тик раз в 2 секунды (аккумулятор в `Game.updatePlaying`).
- Капы: ≤ 12 мирных и ≤ 8 зомби одновременно.
- Попытка спавна: случайная точка в кольце 20–48 блоков от игрока, только в
  загруженном чанке; ищется поверхность (верхний solid-блок, над ним 2 блока
  воздуха).
- Мирные: только на блоке GRASS, в любое время суток (докидываются до капа).
- Зомби: только ночью (daylight-фактор < 0.3), не ближе 16 блоков к игроку.
- Деспавн: моб дальше 72 блоков от игрока удаляется.
- Мобы не сохраняются: `SaveManager`/`LevelData` не меняются.

## Бой: игрок → моб

- ЛКМ: до рейкаста по блокам — параметрический ray-vs-AABB тест по всем мобам
  в радиусе 4.5 блока. Если моб ближе, чем блок под прицелом — удар по мобу
  (блок не ломается, кратер не начинается).
- Урон рукой: 2 (1 сердце). Кулдаун — существующий свинг руки.
- Реакция: горизонтальный knockback от игрока, красная вспышка тинта 0.4 с,
  звук hurt.
- HP ≤ 0 → звук death, облако частиц (цвет из скина моба), моб удаляется.
- В CREATIVE удары работают так же (мобов можно убивать).

## Рендер: MobRenderer + MobSkins

**Модель** — набор кубоидов на тип моба:
- Четвероногие (COW, PIG, SHEEP): голова, тело (горизонтальное), 4 ноги.
- CHICKEN: голова с клювом, тело, 2 ноги, 2 крыла (прижаты).
- ZOMBIE: голова, торс (вертикальный), 2 ноги, 2 руки, вытянутые вперёд.

**Текстуры** — одна текстура на MobType (индивидуальный GL-текстур-объект,
не в блочном атласе):
- `MobSkins.generate(MobType)` рисует пиксельный скин в `BufferedImage`
  (корова — бурая с белыми пятнами, свинья — розовая с пятачком, овца — белая
  шерсть + розовая морда, курица — белая с жёлтым клювом и красной бородкой,
  зомби — зелёная кожа, синяя рубаха, тёмные штаны).
- Если существует `assets/mobs/<type>.png` — грузится он вместо процедурного
  (той же UV-раскладки). Раскладка UV фиксируется в плане реализации.

**Шейдер `MOB`** (в `Shaders.java`): вершины частей тела в локальных
координатах, uniform-матрица модель×вид×проекция на часть тела, текстура ×
uniform-свет. Свет = sky-light блока, в котором стоит моб (тот же расчёт, что
для чанков) × daylight-фактор — мобы темнеют ночью и в тени.

**Анимация:**
- Ноги качаются синусом от пройденного пути (как у MC).
- Голова поворачивается к направлению движения; у зомби в CHASE — на игрока.
- Красная вспышка урона: uniform-тинт при отрисовке 0.4 с после удара.

**Порядок отрисовки:** после opaque-чанков, до частиц и HUD.

## Тестирование

`TestMain` (plain main + asserts, без GL):

- `EntityPhysics`: падение на блок → `onGround=true`, скорость обнулена;
  движение в стену → `hitWall=true`, позиция не проходит сквозь блок.
- ИИ: зомби при игроке в 10 блоках переходит в CHASE; при 30 блоках — WANDER;
  кулдаун атаки не даёт бить чаще 1 раза в секунду; мирный моб после hurt —
  FLEE.
- MobSpawner: не превышает капы; зомби не спавнится днём; мирный не спавнится
  на камне.
- `MobSkins.generate`: для каждого типа возвращает непустой BufferedImage
  правильного размера; скины разных типов попиксельно различаются.

Рендер, анимация и звук проверяются вручную через `.\run.ps1`.

## Вне области E1 (YAGNI на этот цикл)

- Дроп с мобов (мясо, кожа, перья) — после системы предметов (C).
- Pathfinding (A*, обход препятствий) — зомби ходит по прямой + прыжки.
- Разведение, приручение, стрижка овец.
- Скелет/крипер/паук — добавляются строкой в MobType в следующих циклах.
- Персистентность мобов в сейве.
- Огонь как визуальный эффект (горение зомби — только урон + дым).
