# Система биомов (v1)

Дата: 2026-06-11
Статус: утверждено пользователем (брейншторм в Claude Code)

## Цель

Добавить в генератор мира систему биомов в духе Minecraft: пять биомов (равнины, лес, пустыня, тундра, океан), влияющих на высоту рельефа, блоки поверхности и растительность. Без побиомной тонировки травы — биомы различаются отдельными типами блоков.

## Не входит в v1

Лёд в тундре, снежный покров-слой, цветы/высокая трава, берёзы, болота, горы, реки, сохранение биома в чанке, побиомные звуки/цвет неба. Архитектура не должна им мешать, но реализовывать их сейчас не нужно.

## Архитектура

### BiomeProvider (новый класс, `world/BiomeProvider.java`)

Детерминированный источник биомов: создаётся от сида мира, владеет тремя низкочастотными `PerlinNoise` с производными сидами (XOR с разными константами, по образцу `detailNoise` в `World`):

- **континентальность** — отделяет океан от суши;
- **температура** — холод/жара;
- **влажность** — сухо/влажно.

Частота климатических шумов значительно ниже рельефной (~0.0015–0.003 на блок), чтобы биомы были регионами в сотни блоков.

`Biome biomeAt(int wx, int wz)`:

1. `continentalness < C_OCEAN` → `OCEAN`;
2. иначе по таблице климата:
   - `temp < T_COLD` → `TUNDRA`
   - `temp > T_HOT && humidity < H_DRY` → `DESERT`
   - `humidity > H_WET` → `FOREST`
   - иначе → `PLAINS`

Пороги — константы в `BiomeProvider`, подбираются при тюнинге.

### Biome (новый enum, `world/Biome.java`)

Каждая константа несёт параметры генерации:

| Поле | Назначение |
|---|---|
| `baseHeight` | базовая высота поверхности (отступ от SEA_LEVEL) |
| `amplitude` | множитель амплитуды рельефного шума |
| `surfaceBlock` | блок верхнего слоя |
| `fillerBlock` | блок под поверхностью (4 слоя до камня) |
| `treesPer128` | плотность деревьев (порог для существующего hash-критерия `(h & 0x7F)`) |
| `treeType` | `OAK` / `SPRUCE` / `CACTUS` / `NONE` |

Ориентировочные значения (тюнингуются):

| Биом | baseHeight | amplitude | surface | filler | растительность |
|---|---|---|---|---|---|
| PLAINS | SEA_LEVEL+6 | 0.4 | GRASS | DIRT | дубы, очень редко (1/128) |
| FOREST | SEA_LEVEL+6 | 0.7 | GRASS | DIRT | дубы, плотно (~8/128) |
| DESERT | SEA_LEVEL+6 | 0.5 | SAND | SAND | кактусы (~2/128) |
| TUNDRA | SEA_LEVEL+7 | 0.8 | SNOWY_GRASS | DIRT | ели (~3/128) |
| OCEAN | SEA_LEVEL−18 | 0.3 | SAND | SAND | нет |

Правило «песок у кромки воды» (`height <= SEA_LEVEL+1` → SAND) сохраняется для всех биомов поверх surfaceBlock.

### Сглаживание высот на границах

Чтобы на стыке биомов не было обрывов, `baseHeight` и `amplitude` для колонки — это среднее по биомам сетки 5×5 сэмплов вокруг колонки с шагом 4 блока (покрытие ±8 блоков). Сэмплы попадают на мировые координаты, кратные 4, поэтому на чанк нужен кэш ~9×9 значений биома (чанк 16×16 + поля ±8): `BiomeProvider` лишь ~81 раз вызывается на чанк вместо 256×25.

Биом самой колонки (для выбора блоков поверхности и деревьев) берётся точечно, без сглаживания — границы блоков поверхности резкие, как в Minecraft.

### Изменения в World.generate()

Проход 1 (рельеф):

```
params = smoothedParams(wx, wz)          // среднее baseHeight/amplitude по 5×5
height  = (int)(params.baseHeight + n * 22 * params.amplitude + d * 4)
biome   = biomeAt(wx, wz)                // точечный — для блоков
surface = biome.surfaceBlock / fillerBlock (с сохранением правила пляжа)
```

Проход 2 (растительность) — по `biome.treeType`:

- **OAK** — текущая форма дуба без изменений;
- **SPRUCE** — конусная крона из существующих `WOOD`/`LEAVES`: ствол 5–7, кольца листвы радиусом 2-1-2-1-1-0 снизу вверх, верхушка из 1 листа;
- **CACTUS** — колонна `CACTUS` высотой 1–3 на песке, без листвы;
- **NONE** — пропуск.

Ограничение «дерево целиком в чанке» (x,z в [2..13]) сохраняется.

## Новые блоки

В `BlockType` добавляются в конец (id блоков — порядковые, вставка в середину сломала бы сейвы):

| Блок | Свойства | Тайлы |
|---|---|---|
| `SNOWY_GRASS` | как GRASS, hardness 0.6 | top: `snowy_grass_top`, side: `snowy_grass_side`, bottom: `dirt` |
| `CACTUS` | solid, cutout=false, hardness 0.4 | side: `cactus_side`, top/bottom: `cactus_top` |

Кактус в v1 — полный куб (без вреза на 1px и урона при касании).

Тайлы добавляются в конец `TextureAtlas.TILE_NAMES` (следующий свободный индекс — 47). PNG-спрайты генерируются одноразовым скриптом из существующих: `snowy_grass_top` — белый снег с шумом, `snowy_grass_side` — `grass_side` с белой верхней полосой, кактус — рисуется процедурно (зелёный с тёмными вертикальными полосами). Скрипт кладёт PNG в каталог блоков; фоллбэк-placeholder атласа страхует от опечаток.

Звуки: `Sounds.materialOf()` — `SNOWY_GRASS` → материал grass (или snow, если в `assets/sounds` есть snow-набор — проверить при реализации), `CACTUS` → cloth/grass-подобный из доступных.

## Совместимость сейвов

Биом нигде не сохраняется — вычисляется от сида. Уже сгенерированные чанки старых миров не меняются; новые чанки в них генерируются с биомами (возможен шов высот на границе старого/нового — допустимо, поведение как в Minecraft). Новые `BlockType` добавлены в конец enum, старые id не сдвигаются.

## HUD

В debug-оверлей (F3) добавляется строка `Biome: <имя>` для позиции игрока — дёшево и сильно упрощает тюнинг порогов.

## Тестирование

Тестовая инфраструктура уже есть (`src/test/`, `run-tests.ps1`). Новые тесты:

1. **Детерминизм** — два `BiomeProvider` с одним сидом дают одинаковые биомы на сетке точек; разные сиды — различающиеся.
2. **Таблица климата** — юнит-тест функции классификации (подача синтетических значений температуры/влажности/континентальности на все ветки).
3. **Гладкость высот** — на случайных трассах соседние колонки `smoothedParams` отличаются по итоговой высоте не более чем на K блоков (K подобрать, ~3), чтобы границы биомов не давали стен.
4. **Генерация чанка** — чанк в каждом биоме содержит ожидаемый поверхностный блок (по форс-замоканному/подобранному сиду либо через инъекцию `BiomeProvider`-стаба в `World`).

Ручная проверка: запуск `run.ps1`, полёт по миру, осмотр границ биомов и растительности.
