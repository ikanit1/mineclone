# План: часть B — главное меню в `com.mineclone.ui`

Часть A спеки закоммичена в `16af655`. Этот план — только часть B. Шаги идут
так, чтобы меню работало на каждом коммите: новый пакет строится рядом,
экраны переезжают группами, старый код `Hud` удаляется, когда его больше
никто не зовёт.

Проверка каждого шага: `.\run-tests.ps1` зелёный, сборка `out` без ошибок,
`tools\RenderHudPreview.java` рендерит новые кадры без GL-ошибок.

## Решения, принятые по ходу (в спеке их не было)

- **Язык меню — русский.** Шрифт с `Font.RANGES` уже пакует кириллицу,
  тосты и этапы загрузки уже русские. Английские подписи старого меню уходят
  вместе с ним. В инструментах предпросмотра кириллических литералов нет:
  лаунчер читает исходник в системной кодировке — строки берутся из
  скомпилированных экранов.
- **Переназначаются только клавиши клавиатуры.** Кнопки мыши (удар,
  установка, выбор блока) остаются жёсткими. F1/F3/F4/F5/F6/F11 и Esc —
  системные: захват их не принимает, иначе действие молча перекрыло бы
  отладку или выход из меню.
- **Раскладка пишется по имени действия, а не по порядку.** Добавление или
  перестановка действий не сдвигает чужие клавиши в старых настройках.
- **`LevelData` не поднимается.** Экрану создания мира нужны имя, сид и режим —
  всё это уже есть в формате v9. Дальность прорисовки — общая настройка
  (`Options`), экран создания показывает её для удобства. Версия без нового
  поля — это только риск без пользы.
- **Логотип рисуется блоками атласа** (пиксельный шрифт 5×7, верхний пиксель
  буквы — трава), а не третьим кеглем TTF: крупный кегль с кириллицей не
  помещается в атлас шрифта 1024×512.
- **Экран загрузки рисуется поверх живого фона меню**, а не полусобранного
  мира: фон уже загружен и дешёвый, а мир во время загрузки дёргается кусками.
- **«Продолжить» на титульном экране** — последний сыгранный мир одной кнопкой.

**Отступление от порядка.** Экраны задач 3–5 подключены к `Game` одним шагом,
когда все были готовы и проверены снимками, — переходный код «новый титул
открывает старый список миров» не понадобился. Меню работало на каждом
коммите: до подключения новые экраны просто никто не звал.

**Проверка в настоящей игре.** `-Dmineclone.autopilot=<папка>` (вместе с
`-Dmineclone.savesDir=<папка>`, чтобы не трогать миры игрока) проходит титул →
миры → создание → загрузку → игру → паузу → настройки → клавиши → главное
меню, снимает кадр на каждом шаге и падает с ненулевым кодом, если превью
мира не записалось. Первый прогон нашёл то, чего не видно в офлайновых
снимках: кнопки титула без подложки сливаются с ярким небом, а полоса
загрузки отставала от этапов.
