Mineclone dedicated server

Install Java 17 or newer. Extract the complete archive into a writable folder,
edit server.properties, then run start-server.bat. No graphical window is needed.
Connect a game client to this machine's IP and the configured TCP port.
Type /help for console commands and /stop to save the world and stop cleanly.
Worlds are stored in saves/. Keep backups before updating the server build.
Photon and UPnP are disabled in the example configuration.
